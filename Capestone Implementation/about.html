Academic Project Specification

Design and Implementation of a Web-Based Analytical Framework for Daily Stock Price Forecasting

A comprehensive technical overview of the computational architecture, mathematical formulations, and software engineering design.

Project Objectives

The objective of this research and software implementation is to develop a complete, professional, responsive web-based stock price forecasting application utilizing pure C++ as the primary backend programming language alongside modern frontend technologies.

Native C++ High Performance

Execute all data ingestion, preprocessing, technical indicators, and multi-step forecasting strictly within optimized C++ algorithms with zero Python or Node runtime dependency.

SQLite Persistence

Embed SQLite3 to store company master profiles, historical daily OHLCV prices, and audited prediction records with WAL-enabled concurrency.

Visual Analytics & Error Metrics

Deliver intuitive financial charts, confidence bands, holdout test split validation (MAE, MSE, RMSE, R²), and transparent trading recommendations.

Detailed Module Specifications

Module 1: Data Ingestion and Preprocessing

Dataset Ingestion, Cleaning & Normalization Engine (C++ STL)

Responsible for collecting, validating, organizing, and preparing raw time-series financial datasets before modeling. Raw price streams often suffer from missing quotes, non-trading weekend gaps, duplicate records, or extreme scale differences across international currencies (INR vs USD).

Preprocessing Capabilities:
  • Chronological sorting and temporal deduplication
  • Forward-fill and linear interpolation for zero or corrupted values
  • Calculation of daily percentage price changes
  • Three-sigma statistical outlier detection
  • Integration with embedded SQLite database tables
Normalization Formulations:
Min-Max Normalization:
x' = (x - x_min) / (x_max - x_min)

Z-Score Standardization:
z = (x - μ) / σ

Module 2: Predictive Modelling and Analytical Engine

Mathematical Forecasting & Technical Indicator Framework (C++)

Implements closed-form analytical algorithms to predict future stock prices for 7, 15, and 30 trading days. Also performs backtest validation on recent holdout test sets to calculate genuine statistical error metrics.

Simple Moving Average (SMA)

Autoregressive rolling multi-step projection with momentum drift decay.

SMA_t = (1/W) Σ P_{t-i}
Linear Regression (OLS)

Ordinary least squares fitting slope (β) and intercept (α) over time steps.

y = α + βx
Exponential Moving Avg (EMA)

Weighted smoothing giving exponential weight to recent price changes.

EMA_t = αP_t + (1-α)EMA_{t-1}
Statistical Error Metrics:
MAE: (1/M) Σ |y_i - ŷ_i|
MSE: (1/M) Σ (y_i - ŷ_i)²
RMSE: √(MSE)
R²: 1 - (SS_res / SS_tot)

Module 3: Web-Based User Interface & Visualisation

Financial Dashboard & Real-Time Analytics UI

Provides a premium dark financial terminal featuring responsive layouts, Chart.js interactive graphs with 95% confidence bands, dynamic ticker marquees, technical indicator meters, daily price inspection tables, and one-click CSV report exporting.

Frontend Stack:
  • HTML5 / CSS3: Custom Dark Financial theme with CSS variables
  • Bootstrap 5: Responsive grid and modern layout containers
  • JavaScript (ES6+): Async/await REST API client, data formatting
  • Chart.js: Interactive canvas rendering with gradients & tooltips
  • Font Awesome: Semantic financial & metric iconography
REST API Communication:
  • GET /api/stocks - Stock list & daily statistics
  • GET /api/stocks/history - OHLCV historical time series
  • POST /api/data/preprocess - Clean & normalize datasets
  • POST /api/predict - Execute C++ forecasting algorithm
  • GET /api/analytics - Technical indicators (RSI, MACD, BB)

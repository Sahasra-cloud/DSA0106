System Architecture

Three Integrated Computational Modules

Built completely with high-performance native C++ algorithms and responsive JavaScript data visualizers.

Module 1: Ingestion & Preprocessing

Robust C++ STL pipeline handling missing values, temporal deduplication, daily return calculations, Min-Max [0, 1] normalization, and Z-score standardization.

  • Clean & deduplicate historical datasets
  • Min-Max & Z-Score Normalization
  • SQLite embedded persistence

Module 2: Predictive Modelling Engine

Genuine C++ mathematical forecasting implementing Simple Moving Average (SMA), Ordinary Least Squares Linear Regression, and Exponential Moving Average (EMA).

  • 7, 15, and 30-Day price projections
  • Validation error metrics (MAE, MSE, RMSE, R²)
  • Transparent Buy/Sell/Hold decision engine

Module 3: Visualisation & Reports

Modern financial terminal powered by Chart.js, Bootstrap 5, responsive layouts, candlestick/line charts, confidence interval envelopes, and one-click CSV export.

  • Interactive forecast & historical charts
  • RSI, MACD, Bollinger Bands panels
  • Export full reports & logs to CSV
